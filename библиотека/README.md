Правила и стандарты, руководства действующих СДП, описания датчиков, учебные материалы. Собрано с Яндекс.Диска владельца (папка «Загрузки») 16.11.2026; повторы убраны, файлы переименованы понятно. Снимки экранов K-Pos уменьшены до 1800 точек по длинной стороне.

⚠ **Только для этого закрытого репозитория.** Документы производителей, IMCA, ABS и РС защищены правами издателей. Их нельзя выкладывать наружу, пересылать или вставлять в открытые отчёты; можно цитировать несколько строк со ссылкой (файл, страница). Сделать репозиторий открытым можно только после удаления этой папки из всей истории.

⚠ Редакции — как в файлах, не новейшие. Агент 4 сверяет их с действующими (`отчёты/правила/реестр.md`).
