# Пульт: этап 1 дорожной карты (вкладки, палитры, раскладка, бортовой режим)

Дата: 2026-11-18. Ветка: `пульт-этап1`. Ядро C++ не менялось — только QML-отображение (`hmi/qml/`) и разбор аргументов командной строки пульта (`hmi/main.cpp`).

## Что сделано

### 1. Вкладки пульта (9 шт)
Верхняя полоса вкладок по дорожной карте: **Главный, Опорные системы, Движители, Тренды, Возможности, Анализ отказов, Тревоги, Мощность, Настройки**.

- **Главный** — прежний состав экрана: план позиционирования, курс и скорость, режим (Ожидание/Курс/Позиция, взять/снять движители), сдвиг точки, среда, краткий анализ последствий (кнопки Класс 2/3/Выкл).
- **Опорные системы** — список датчиков (MRU, GNSS, лазер, гирокомпасы, анемометры) с типом и текущим значением.
- **Движители** — плитки по каждому движителю: упор, задание/факт угла, мощность и обороты, статус управления.
- **Тренды** — история в памяти пульта (1 Гц, до 60 минут): ошибка позиции, загрузка движителей, ветер, мощность; окна 5/15/60 мин.
- **Возможности** — запас по осям: требуемое ядром усилие против предела движителей (X, Y, момент на курс) с процентами. Полярная диаграмма возможностей по ветру — в планах (в ядре есть, на пульт ещё не выведена).
- **Анализ отказов** — полная панель анализа последствий отказа (выбор класса, результаты расчёта).
- **Тревоги** — активный список, журнал, командная строка, квитирование.
- **Мощность** — итог кВт, распределение по группам отказа (ГРЩ), таблица по движителям.
- **Настройки** — выбор палитры, бортовой режим, сведения о программе.

Шапка состояния, строка тревог и индикация режима видны на всех вкладках — не убираются ни в одном наборе.

### 2. Палитры день / сумерки / ночь
`Theme.qml` переписан: все цвета — привязки от `property string scheme` (`day` / `dusk` / `night`).

- **Ночь** — прежняя тёмная палитра (поведение по умолчанию не изменилось).
- **Сумерки** — средняя по яркости тёмная.
- **День** — светлая.

Переключение — на вкладке «Настройки» (сохраняется в `QSettings`) или ключом запуска `--palette day|dusk|night` (разово, в настройки не пишется). Плоттер позиции и плитки движителей перерисовываются при смене схемы (`Connections` на `Theme.schemeChanged`).

### 3. Раскладка для 1366×768
Окно по умолчанию подстраивается под доступный экран (`Screen.desktopAvailable*`, не больше 1920×1080), минимальный размер 1280×700. Проверено снимком при 1366×768: все три колонки главного экрана читаемы, длинные значения (ветер, возмущение, мощность) обрезаются с многоточием, а не вылезают за панель.

### 4. Скрытие команд имитатора на судне
Бортовой режим: чекбокс на вкладке «Настройки» (сохраняется) или ключ `--onboard` (разово). В бортовом режиме скрыты метка «ИМИТАЦИЯ ×20» и кнопки управления имитатором в шапке («Открыть судно…», «Остановить имитатор»).

## Замечания и ограничения

- Для снятия снимков неглавных вкладок добавлен ключ `--tab N` (0–8): программно переключить `TabButton` из тестового контура не удалось (объекты TabButton не находятся через `findChildren`, эмиссия `clicked()` не делает кнопку активной) — обойдено установкой `currentIndex` у TabBar по `objectName: "tabbar"`. ⚠ На поведение пульта у оператора это не влияет, переключение мышью работает.
- Тренды — история только в памяти запущенного пульта (не в ядре, не на диске), шаг 1 Гц по реальному времени, глубина до 60 минут. ⚠ При запуске пульта история пустая и набирается с нуля.
- Полярная диаграмма возможностей по ветру не выведена (данные в ядре есть) — запланировано в дорожной карте; на вкладке «Возможности» об этом есть подпись.
- В строку тревог вошли два ряда А/W и счётчик неподтверждённых — часть пункта А.1 списка доработок уже выполнена здесь.
