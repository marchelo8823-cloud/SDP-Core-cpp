# Пульт: строка тревог по образцу K-Pos (группа А)

Дата: 2026-11-18. Ветка: `пульт-тревоги` (от `main`). Продолжение этапа 1 дорожной карты — вывод 1 из разбора снимков K-Pos: «Шапка: разделить W/A в два ряда, счётчик неподтверждённых, раскрытие списка тревог из шапки». Два ряда А/W и текстовый счётчик появились в предыдущем этапе (`PR_hmi_tabs.md`); здесь строка тревог доведена до конца.

## Что сделано

### 1. Пульт читает динамическую страницу менеджера тревог ядра
`hmi/hmicore.cpp` больше не строит свой список из сырого `out().alarms` и не ведёт отдельное множество квитированных — берётся `Core::alarms().records()` (тот же источник, что у консоли `sdp_run`):

- у каждой записи есть **время появления** (`tFirst`), **число повторов** (`count`), состояние **«условие ушло»** (`AlarmNormal`, ждёт квитирования), признак квитирования;
- сортировка: по важности, внутри класса новые сверху — в ряду шапки всегда последнее сообщение, как в K-Pos;
- квитирование идёт через `AlarmMgr::ack()` ядра: попадает в журнал событий (`EvAck`), а вернувшаяся тревога снова становится неквитированной — это поведение ядра, пульт его не дублирует;
- добавлено квитирование по одной тревоге: `HmiCore::ackCode(code)`.

Логика возникновения/снятия тревог в ядре не менялась — только источник данных для показа.

### 2. Раскрытие списка из шапки
Щелчок по ряду А или W раскрывает под строкой список класса: время появления (`t+N с`), код, текст, `×N` при повторах, пометка «условие ушло», кнопка «Квит.» по каждой записи. Повторный щелчок или «Скрыть» сворачивает. Красный ряд (А) теперь включает и аварийные сообщения (приоритет 0), раньше они в ряд не попадали.

### 3. Колокол со счётчиком неподтверждённых
Текстовая рамка «не квитировано: N» заменена колоколом (рисуется на Canvas, без зависимости от шрифтов с эмодзи) с красным бейджем-цифрой — как в K-Pos. Щелчок по колоколу открывает вкладку «Тревоги». При нуле неподтверждённых бейдж скрыт, колокол серый. Считаются тревоги и предупреждения, информационные сообщения (уровень 3) в счётчик не входят.

### 4. Вкладка «Тревоги»
В записи добавлены время появления, число повторов, пометки «условие ушло» / «квитировано» и кнопка квитирования по одной записи.

### 5. Ключ для проверок
`--alarms A|W` — открыть раскрытый список ряда при запуске (для снимков; как `--tab`).
