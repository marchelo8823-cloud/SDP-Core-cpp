# План: анализ последствий отказа (Consequence Analysis)

Статус: **предложение на одобрение владельца**. Код не менялся. ⚠ Изменение влияет на безопасность (новые тревоги, связь с распределителем упоров) — после одобрения делается отдельной веткой, проверяет тестировщик.

## Основание

| Документ | Что требует |
|---|---|
| РС ч. XV, 8.9.5 (`библиотека/правила/РС_Правила_ч.XV_Автоматизация_2025-07-01.pdf`, с. 94) | для классов 2 и 3 — непрерывный анализ: оставшиеся после наихудшего отказа движители дают те же результирующие упор и момент, что требовались до отказа, при имеющейся погоде |
| РС 8.9.6 | тревога, если при наихудшем отказе удержание станет невозможным |
| РС 8.9.7 | для долгих операций — моделирование наихудшего отказа по погоде, введённой вручную |
| MSC.1/Circ.1580, 3.4.2.4 | то же; поправка на взаимное влияние движителей (3.3.4) |
| K-Pos 7.0, разд. 18 (с. 271–273) | раз в минуту в Auto Position при неизменных уставках, если выбран класс 2 или 3 (по умолчанию выключен); тревога «drift off warning» с пояснением «thrust critical if thrusters 1-4 lost» |
| Mega-Guard, 5.4.1 | постоянно в автопозиционировании, тревога при недостатке упора |

## Что уже есть в ядре

- `capHolds()` (`include/dp/capability.hpp:56`) — хватает ли распределителю движителей на заданное усилие при заданном наборе движителей; колонки доводятся до установившихся углов.
- `capScenarios()` — по запросу (`cap`): предельный ветер при отказе каждого движителя по отдельности.
- `capHypot()` — гипотетический случай: отказы движителей и шин A/B, ветер, течение, дрейф.
- ⚠ Электростанции в ядре нет: анализ будет **только по упору**, не по мощности.

## Что предлагается

### 1. Расчёт
- Когда: каждые **60 с**, если режим «Позиция» (по желанию — и «Курс»), уставка не меняется и нет возврата (POS_RETURN), выбран класс 2 или 3. Во время смены точки или курса — пауза без сообщений (как K-Pos).
- Что требуется сейчас: среднее за последние 60 с усилие регулятора (сила вдоль, поперёк и момент) — в нём уже ветер, течение, волна.
- Для каждой группы наихудшего отказа: те же движители без этой группы, полный упор → `capHolds()`. Итог — запас по силе и моменту, %.
- Поправка на взаимное влияние движителей — та, что уже есть в распределителе (запретные зоны); отдельной не добавляется.

### 2. Группы наихудшего отказа (данные судна)
- Новая **необязательная** колонка на листе движителей: «Группа отказа» — одно или несколько имён через «;» (например, «ГРЩ-1», «МО-1»). Движители с одним именем отказывают вместе.
- Если групп нет, а класс 2 или 3 выбран: анализ по отказу каждого движителя по отдельности и предупреждение «группы наихудшего отказа не заданы — анализ по одиночным отказам». Ядро ничего не придумывает за судно.
- Шаблон книги, редактор `sdp_ship`, проверка книги — дополняются.

### 3. Сообщения
| Код | Вид | Текст (пример) |
|---|---|---|
| CA_RUN | сообщение | Анализ последствий: класс 2, проверено групп — 3 |
| CA_DRIFT_OFF | **тревога** | Анализ последствий: при отказе «ГРЩ-1» не хватит упора — набрано 72 % силы, 60 % момента. Включите движители или смените курс |
| CA_NO_GROUPS | предупреждение | Группы наихудшего отказа не заданы — анализ по одиночным отказам |
| CA_STOP | сообщение | Анализ последствий остановлен (режим или команда) |

Гистерезис: тревога ставится после двух расчётов подряд с недостатком, снимается при запасе больше 5 % — чтобы не мигала на порывах.

### 4. Команды и пульт
- `class 2|3|off` — выбрать класс (по умолчанию выключено, как K-Pos); `ca` — посчитать сейчас и показать запас по группам.
- РС 8.9.7: `ca <ветер м/с> <откуда °> [течение м/с]` — тот же расчёт по введённой погоде (на основе `capHypot()`).
- Пульт: строка «Анализ последствий: класс 2 — запас есть / НЕ ХВАТИТ при отказе …», окно со списком групп и запасом.

### 5. Проверка
- Книга судна с группами (2 ГРЩ) в `tests/books/`.
- Имитатор: ветер 8 м/с — тревоги нет; ветер растёт до значения, при котором одна группа не тянет (по `cap`) — CA_DRIFT_OFF с именем группы; ветер снижается — тревога снимается.
- Смена точки — анализ на паузе, ложной тревоги нет.
- Сверка: на той же погоде анализ согласуется с `cap` (предельный ветер при отказе группы).
- Без групп — CA_NO_GROUPS и одиночные отказы.

### 6. Объём
Около 300–400 строк в ядре (новый файл `include/dp/consequence.hpp`, вызов из `engine.hpp`), книга и редактор, пульт, тесты. Расчёт раз в минуту по 3–8 группам — нагрузка ничтожная.

## ⚠ Ограничения
- Только упор: без электростанции «power critical» (K-Pos) не определяется.
- Требуемое усилие — среднее за минуту; резкий рост ветра анализ увидит с задержкой до 1–2 мин.
- Результат — оценка по модели ядра, а не расчёт по правилам; на испытаниях сверить с FMEA судна.
