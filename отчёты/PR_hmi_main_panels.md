# Пульт: главный экран — отклонение, гирокомпасы, мощность (группа Б)

Дата: 2026-11-18. Ветка: `пульт-главный` (от `main` после слияния PR #37). Вывод 3 разбора снимков K-Pos: «На главный экран добавить: Position deviation (круговой), статус гирокомпасов 1-2-3, шкалу Power consumption». Только QML-отображение, ядро не менялось.

## Что сделано

### 1. Круговой индикатор отклонения позиции
Правая колонка главного экрана, панель «Отклонение позиции» (Canvas):

- кольцо допуска = 5 м, нос вверх, крест — заданная точка;
- точка судна: положение относительно точки (по `errAlong`/`errCross`), за пределами кольца — на ободе;
- сектор ±12° вокруг направления отклонения (как сектор у K-Pos), при превышении 5 м точка и сектор жёлтые;
- цифра отклонения с сотыми, текст «судно N м к носу/к корме · M м к ПрБ/к ЛБ»;
- нет положения — «НЕТ» красным; счисление — цифра жёлтая.

### 2. Статус гирокомпасов 1-2-3
Кружки с номерами в шапке панели «Курс и скорость», рядом с плашкой источника курса (как в K-Pos):

- зелёный — данные в норме;
- жёлтый — расхождение с курсом решения > 1° или датчик отбракован;
- красный — нет данных.

Состав кружков следует за книгой судна (сколько гирокомпасов заведено, столько и показано).

### 3. Потребление мощности: шкала + мини-тренд
Правая колонка, панель «Потребление мощности»:

- вертикальная шкала 0…установленная мощность (сумма `powerMaxKW` движителей, для примера — 2200 кВт), риски 0 / ½ / max, заливка зелёная, при > 90 % — жёлтая;
- справа мини-тренд за 15 минут из истории пульта (1 Гц), при пустой истории — «история набирается…»;
- цифра «текущая / установленная» кВт в заголовке.

### 4. Попутная правка дневной палитры
Плашки «по гирокомпасам» и «в управлении» (плитки движителей) в дневной палитре были нечитаемы (тёмный текст на тёмно-зелёном) — текст сделан белым во всех палитрах.
