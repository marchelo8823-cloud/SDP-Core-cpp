# PR: выгрузка записи сеанса с пульта

Дата: 2026-11-18  
Ветка: `пульт-выгрузка-записей` → `main`

## Что добавлено

Пульт автоматически ведёт штатный CSV-журнал ядра для каждого запуска. Файл сеанса создаётся в каталоге данных приложения, в подкаталоге `записи`; имя содержит время UTC и номер процесса, поэтому одновременно запущенные пульты не используют один файл.

На вкладке «Настройки» добавлен блок «Запись сеанса»:

- состояние автоматической записи;
- имя файла и его текущий размер;
- кнопка «Выгрузить CSV» с системным диалогом выбора места сохранения;
- результат последней выгрузки или понятное сообщение об ошибке;
- пояснение о содержимом журнала и совместимости с `tools/sdp_report.py`.

Выгрузка сбрасывает буферы текущего журнала и сохраняет его актуальную копию через `QSaveFile`. Запись сеанса при этом продолжается. Существующий выбранный CSV заменяется после подтверждения в системном диалоге; при ошибке записи не остаётся наполовину обновлённый файл. Выгрузка поверх самого активного журнала запрещена.

Для проверок без экрана добавлен ключ `--export-recording <файл.csv>`. При совместном использовании со `--screenshot` ошибка выгрузки даёт код выхода 7.

## Что не менялось

Состав столбцов, период и алгоритм записи ядра не изменялись. В ядро добавлены только доступ к состоянию журнала и принудительный сброс буферов для актуальной копии. Выгрузка NMEA и новые форматы отчётов в этот PR не входят.

## Проверка

- Сборка всего проекта — успешно.
- Полный набор: **43/43 теста пройдены**, общее время 282,49 с.
- Новый `hmi_recording` запускает удержание, выгружает CSV поверх заранее созданного старого файла и проверяет штатный заголовок.
- Тот же тест открывает выгрузку через `tools/sdp_report.py` и требует раздел «Удержание» и строку «Ошибка положения, м».
- Проверены снимки на 1366×768 и 1920×1080: состояние записи, кнопка, результат выгрузки и пояснение читаются без обрезки.
- `git diff --check` — без ошибок.
