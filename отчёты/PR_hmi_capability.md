# Пульт: полярная диаграмма возможностей с условиями среды (группа В)

Дата: 2026-11-18. Ветка: `пульт-возможности` (от `main` после слияния PR #38). По образцу Capability plot в K-Pos: предельный и рабочий ветер по направлениям, сценарии отказов и окно условий расчёта. Изменены только пульт и показные поля `HmiCore`; алгоритмы ядра не менялись.

## Что сделано

### 1. Полярная диаграмма возможностей
Вкладка «Возможности» теперь содержит полноразмерную полярную диаграмму:

- нос судна сверху, направления от носа по кругу, спицы через 30°;
- кольца 10 / 20 / 30 / 40 м/с;
- голубая замкнутая кривая с заливкой — предельный ветер при полном упоре, все движители;
- зелёная кривая — рабочий ветер при 80 % упора, все движители;
- тонкие жёлтые кривые — предельный ветер при отказе каждого движителя по отдельности; показ отказов отключается флажком «отказы»;
- фиолетовая точка — текущий измеренный ветер: направление от носа и скорость;
- легенда под диаграммой и понятное пустое состояние до первого расчёта.

Диаграмма использует готовый расчёт ядра `capScenarios`: 36 направлений с шагом 10°, сценарии «Все движители» и отказ каждого движителя.

### 2. Окно условий среды
Справа от диаграммы добавлена панель условий расчёта:

- течение, м/с (в расчёт передаётся в диапазоне 0…5);
- волны по ветру `Hs = 0,0246·V²` либо без волн;
- максимальный ветер поиска, м/с (в расчёт передаётся в диапазоне 5…60);
- кнопка «Рассчитать возможности»;
- строка фактических условий: текущий ветер от носа и значительная высота волны, если она есть;
- строка параметров последнего расчёта и время модельных часов, на которое он выполнен.

Расчёт запускается явно по кнопке, а не на каждом цикле пульта. До загрузки судна кнопка недоступна.

### 3. Сводка по сценариям
Под условиями выведен список всех рассчитанных сценариев. Для каждого показаны наименьшие по всем направлениям значения:

- предельный ветер, м/с;
- рабочий ветер (80 % упора), м/с.

Для демонстрационного судна при течении 0,0 м/с и волнах по ветру получено: все движители — 21,5 / 19,7 м/с; отказы AZ1 и AZ2 — 19,7 / 17,6 м/с; BOW1 — 16,7 / 15,4 м/с; BOW2 — 17,1 / 15,8 м/с.

Прежняя панель «Запас по осям: требуемое усилие / предел» сохранена внизу вкладки.

### 4. Связь QML с ядром
В `HmiCore` добавлены только показные свойства `capCurves`, `capInfo` и метод `capRun(...)`. Метод преобразует результаты `capScenarios` в `QVariantList` для QML и сообщает об обновлении через `capChanged`. Расчёт возможностей не участвует в решении регулятора и не меняет команды движителям.

## Ограничения

- Это оценка по средним силам модели ядра, а не сертифицированный расчёт по правилам РС.
- Курс принят постоянным; ветер, волна и течение в каждом расчётном направлении действуют с одной стороны.
- Расчёт не обновляется автоматически при изменении среды — после изменения условий нужно снова нажать кнопку.
- Шкала отображения фиксирована на 40 м/с. Предел поиска можно задать до 60 м/с, но значения выше 40 м/с на диаграмме прижимаются к внешнему кольцу; точные минимальные значения остаются в списке сценариев.
- Жёлтые кривые показывают отказы отдельных движителей, а не группы наихудшего отказа из анализа последствий отказа.
