# Как собрать и запустить СДП (v0.28)

Проект собирается CMake. Окно оператора (HMI) требует Qt 6.4 или новее; ядро и тесты — только компилятор C++17.
⚠ Проверено только на Linux. Сборка на Mac и Windows по этой инструкции не проверялась.

## macOS (MacBook Air)
1. Откройте Терминал, перейдите в папку проекта: `cd ~/Downloads/dpcpp` (путь свой).
2. Одна команда ставит Qt и CMake через Homebrew и собирает всё: `bash scripts/build_hmi_mac.sh`
   (если Homebrew нет — сначала https://brew.sh).
3. Запуск окна оператора — из папки проекта (не из build/hmi), пути к настройкам и карте — от неё:
   `./build/hmi/sdp_hmi.app/Contents/MacOS/sdp_hmi config/salvage73_pms.json --speed 5 --map maps/demo_chart.png`
   Если вы уже в `build/hmi`: `./sdp_hmi.app/Contents/MacOS/sdp_hmi ../../config/salvage73_pms.json --speed 5`
   (ошибка «не удалось открыть файл настроек» значит, что путь к json неверен для текущей папки).
   `--speed 5` — имитация идёт в 5 раз быстрее реального времени (1 — реальное).
4. Если macOS не даёт открыть программу («неизвестный разработчик»): Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».

## Windows 11
1. Поставьте: Visual Studio 2022 Build Tools (рабочая нагрузка «Разработка классических приложений на C++»), CMake (cmake.org) и Qt 6 (онлайн-установщик qt.io, компонент «MSVC 2019/2022 64-bit», версия 6.4 или новее).
2. Откройте «x64 Native Tools Command Prompt for VS 2022», перейдите в папку проекта.
3. Сборка (путь к Qt поправьте под свою установку):
   `cmake -S . -B build -DSDP_BUILD_HMI=ON -DCMAKE_PREFIX_PATH=C:\Qt\6.7.0\msvc2019_64`
   `cmake --build build --config Release`
4. Запуск из папки проекта: `build\hmi\Release\sdp_hmi.exe config\salvage73_pms.json --speed 5`
   Если не находит библиотеки Qt: `C:\Qt\6.7.0\msvc2019_64\bin\windeployqt.exe sdp_hmi.exe`.

## Linux
`cmake -S . -B build -DSDP_BUILD_HMI=ON -DCMAKE_PREFIX_PATH=<путь к Qt 6>` и `cmake --build build -j8`,
затем из папки проекта `build/hmi/sdp_hmi config/salvage73_pms.json --speed 5`.

## Только ядро и консоль (без окна и без Qt)
`cmake -S . -B build && cmake --build build`
- консольная имитация: `build/sdp_run config/salvage73_pms.json` — после запуска можно вводить команды (`help` — список);
- тесты: `cd build && ctest` (36 тестов, около 70 с).

## Два поста оператора и отдельная служба ядра
В одном окне: `sdp_hmi config/salvage73_pms.json --serve 5300` (второй пост подключится по сети).
Отдельно: `build/sdp_core config/salvage73_pms.json --port 5300 --speed 5`, затем в двух окнах
`sdp_hmi --connect 127.0.0.1:5300 --station A` и `--station B`. Первый подключившийся получает управление.
На Mac всё сразу: `bash scripts/run_two_posts_mac.sh`.

## Конфигурации (папка config)
- `salvage73_pms.json` — спасательное судно 73 м, 4 дизель-генератора, шины A/B (основная);
- `navis90_pms.json` — судно NAVIS 90 м; `demo.json` — простой пример.

## Где новое в v0.20
- Окно «Возможности» → переключатель «Гипотеза и дрейф»: отказы, предел упора, ветер, течение → держит ли, дрейф, время до радиуса.
- Остальное — командами (поле ввода команд или консоль `sdp_run`): `pivot bow`, `pivots`, `tal highbias`, `holdarea 10`,
  `ref LASER auto on`, `fusion freeze 10`, `autoexcl on`, `hypot wind=30 from=90`. Полный список — `help`; описание — README, раздел «Версия 0.20».
- Для проверки отказов в имитации: `sim freeze GNSS1 on`, `sim fbfault PU1 -60`, `sim thr off PU1`.

## Где новое в v0.21
- Все страницы — кнопками в левой колонке окна. Новые: «Планировщик», «Внешняя ДП», «Ограничения», «Помощник».
- Планировщик и изменение ограничений — после входа администратора (с v0.23 — страница «Администрирование») (пароль задаётся один раз в окне «Судно» на компьютере ядра).
- Внешняя ДП: добавьте раздел `extlink` в файл настроек; сначала только приём, активный режим — вручную с кодом `ДА-<поставщик>`.
- Помощник: папка `kb` лежит рядом с программой (копируется при сборке). Для Claude API включите запросы и введите ключ на странице (администратор).

## Где новое в v0.22
- Страница «Датчики»: у систем положения режим «Мобильная», диаграмма качества, тесты дисперсии/расхождения, веса (ручные или по повторяемости). Для лазерных радаров — формат Fanbeam (MDL, CEG17, PMDTG) и Artemis (ART17, ART22) в списке «Принимать»; положения мишеней и Fix-станции — командами `sensor <ID> target …` / `sensor <ID> ref …`.
- На верхней панели — статус ДП (зелёный / синий / жёлтый / красный) с подсказкой при наведении. В окне тревог (вид «Стол») под сообщением — «Что делать».
- «Старший»: в окне «Судно» кнопка «Старший…» задаёт пароль; после этого настройки датчиков и расчётов требуют входа (вход — на странице «Администрирование»). Если пароль не задан — как раньше.
- Помощник знает новые разделы базы знаний (процедуры, форматы, словарь сообщений). Описание — README, «Версия 0.22».

## Где новое в v0.23
- **Одна страница «Администрирование»** вместо отдельных «Планировщик», «Ограничения», «Внешняя ДП», «Судно» и «Старший: вход». Вверху один вход (администратор; «Старший» — только если задан его пароль), ниже вкладки: Планировщик судна, Ограничения, Внешняя ДП: связь, Судно и пароли. Просмотр доступен всем, изменения — после входа. Кнопки «Судно» и «Старший: вход» в левой колонке убраны.
- **Связь с внешней ДП настраивается в запущенной программе** (вкладка «Внешняя ДП: связь», блок «Настройка связи»): поставщик, входы UDP / TCP / COM (порт, адрес, скорость), пороги тревог, куда отправлять в активном режиме. «Применить» действует сразу, перезапуск не нужен; настройки сохраняются в папке данных (`extlink.json`) и имеют приоритет над разделом `extlink` файла настроек. Командами: `ext setup <JSON>`, `ext clear`.
- Исправлена ошибка сборки на Mac (QML: `id: gc` совпадал с функцией Qt).

## Где новое в v0.24
- **Запись обмена** — «Администрирование» → вкладка «Запись обмена». Добавьте канал (+ Канал), выберите режим («Приём (пассивно)», «В разрыв», «Опрос Modbus»), линию (UDP / TCP / COM), формат; «Применить каналы» → «Начать запись». Во время записи ставьте метки. Файлы — в папке данных, `capture/<время>-<метка>`: `exchange.csv`, `exchange.pcap` (Wireshark), сырые `.bin`, `report.txt`, `registers.csv`. Эту папку передавайте для анализа.
- Для «Приём (пассивно)» по UDP пакеты должны доходить до этого компьютера (зеркало порта, широковещание, группа); иначе выберите «В разрыв».
- Опрос Modbus только читает. Описание и ограничения — README, «Версия 0.24».

## Где новое в v0.25
- **«Внешняя ДП: связь» → «+ Сигнал»**: описывайте сигналы пропульсивного комплекса, энергосистемы и тревог (начало строки, номер поля, группа, единицы). Значения — в панели «Сигналы внешней системы»; поле «сверять с нашим» показывает разницу с нашими движителями. Для отправки у шаблона задайте предел значения и интервал.
- **«Источники данных»** (новая вкладка): сетевые карты, COM/USB-порты, привязка входов к портам и адресам, «Проверить» линию (только слушает).
- Формат строк Praxis и Kongsberg неизвестен: сначала снимите обмен на вкладке «Запись обмена», затем опишите сигналы. Подробности и ограничения — README, «Версия 0.25».

## Где новое в v0.26
- **Ограничения движения** (панель «Уставка», внизу): оператор сам задаёт максимальную скорость поворота (°/мин) и скорость перемещения (уз). Команды `rate rot 20`, `rate speed 0.8`, `rate rot off`. Предел действует на опорную точку; ручной джойстик не ограничивается. Подробности — README, «Версия 0.26».

## Частые проблемы
- «Qt6 not found» — не указан `-DCMAKE_PREFIX_PATH` на каталог Qt.
- Пустое окно или ошибки QML — нужен Qt 6.4+ с модулями Quick Controls 2 и Network.
- Окно слишком крупное или мелкое: `--size 1400x800`, шрифт — `--font 1.2`.
